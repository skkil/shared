# 한국어에서 독자를 붙잡는 표현

이 표는 한국어 글을 느리게 읽히게 하거나 번역문처럼 보이게 하는 표현입니다. 근거는 `language-ko.md`에 정리한 국립국어원 자료, Microsoft 한국어 현지화 스타일 가이드, 쿠버네티스 한글화 가이드, 토스 UX 라이팅 가이드, KatFishNet(ACL 2025)입니다. `scripts/readability_check.py`가 이 표를 그대로 읽습니다.

걸린 표현은 판정이 아니라 질문입니다. 국립국어원은 '국적을 가지다', '기자 회견을 가지다'를 번역 투로 보지 않습니다. 기계적으로 모두 고치면 오히려 문장이 어색해집니다. 의도한 표현이면 그 줄에 `<!-- vanessa-allow: banned-ko -->`를 붙이세요.

등급: **FAIL** 납품 전 반드시 수정. **WARN** 고치거나 이유를 남김. **INFO** 다시 볼 만함.

## 맞춤법과 띄어쓰기

| Pattern | Level | Why | Instead |
|---|---|---|---|
| `되요` | FAIL | 맞춤법 오류 | 돼요 |
| `몇일` | FAIL | 맞춤법 오류 | 며칠 |
| `금새` | FAIL | 맞춤법 오류 | 금세 |
| `왠만` | FAIL | 맞춤법 오류 | 웬만 |
| `어떻해` | FAIL | 맞춤법 오류 | 어떡해, 어떻게 해 |
| `[가-힣]할수 ?있\|[가-힣] ?수있(다\|습\|어\|는)` | WARN | 의존 명사 '수'는 띄어 씀(한글 맞춤법 제42항) | 할 수 있다 |
| `것같(다\|아\|습\|은)` | WARN | 의존 명사 '것'은 띄어 씀 | 것 같다 |
| `[가-힣](할\|될\|볼)때\b` | WARN | 의존 명사 '때'는 띄어 씀 | 할 때 |
| `뿐만아니라` | WARN | 띄어쓰기 | 뿐만 아니라 |

## 번역 투

| Pattern | Level | Why | Instead |
|---|---|---|---|
| `되어지\|되어진\|되어짐\|되어집\|되어져` | FAIL | 이중 피동 | 되다, 하다 |
| `에 의해서?\|에 의한\|에 의하여` | WARN | 영어 by의 직역 | 행위자를 주어로: "이성계가 건국했다" |
| `(토론\|회의\|만남\|모임\|시간\|대화\|논의\|협의\|휴식\|접촉\|회동)을 가지` | WARN | 동작 명사 + 가지다 | 토론하다, 회의하다, 시간을 보내다 |
| `(권한\|문제\|관계\|기능\|정보)(을\|를) 가지고 있` | WARN | have의 직역(Microsoft 가이드 예) | 권한이 있다, 관계를 맺고 있다 |
| `에 있어서?\b` | WARN | 일본어·영어식 표현 | ~에서, ~할 때 |
| `(와\|과\|에서\|으로\|로\|에게)의 ` | WARN | 조사 + '의' 겹침 | "교수와의 대화" → "교수와 나눈 대화" |
| `(을\|를) (수행\|진행)(하\|합\|했\|됩\|해)` | WARN | 동작 명사 + 수행(Microsoft 가이드) | "삭제를 수행합니다" → "삭제합니다" |
| `(개요\|기능\|정보\|방법)(을\|를) 제공(합\|한\|해)` | INFO | '제공' 남용(Microsoft 가이드) | 간략하게 설명합니다, 보여 줍니다 |
| `하는 것이 (가능\|필요)(하\|합)` | WARN | 명사화로 길어진 문장 | ~할 수 있다, ~해야 한다 |
| `가장 [가-힣]+ (것\|기능\|방법\|도구\|요소) 중 하나` | WARN | one of the most의 직역 | 구체적으로 무엇이 어떤지 쓰세요 |
| `(그것은\|그것을\|그들은\|그녀는\|그는) ` | WARN | 대명사 남용(한국어는 생략이 자연스러움) | 생략하거나 명사를 다시 쓰세요 |
| `(연결\|활성화\|비활성화\|증가\|감소\|향상\|발전)시키` | INFO | 사동 표현 남용 | 연결하다, 활성화하다 |
| `에 대한 ` | INFO | '~에 대한' 남용(Microsoft 가이드: "이 앱에 대한 권한" → "이 앱의 권한") | ~의, 또는 문장을 다시 짜기 |
| `(을\|를) 통해서? ` | INFO | through의 직역이 잦음 | ~로, ~에서 |
| `로부터 ` | INFO | from의 직역 | ~에서, ~에게서 |

## 생성된 글에서 자주 보이는 표현

| Pattern | Level | Why | Instead |
|---|---|---|---|
| `도움이 되(었\|셨)?기를 바랍니다` | FAIL | 대화형 AI 말투 | 지우세요 |
| `(에 대해\|을\|를) (알아보겠습니다\|살펴보겠습니다\|알아볼까요\|살펴볼까요)` | FAIL | 글 자체를 소개하는 서두 | 결론부터 쓰세요 |
| `오늘날 (빠르게 )?(변화하는\|급변하는)` | FAIL | 빈 서두 | 요점부터 쓰세요 |
| `중요한 역할을 (합\|한\|하\|해)` | WARN | 의미 부풀리기 | 구체적인 효과를 쓰세요 |
| `중요성을 (보여\|강조\|시사)` | WARN | 의미 부풀리기 | 그래서 무엇이 달라지는지 쓰세요 |
| `시사하는 바가 크\|새로운 지평\|한 단계 도약\|무궁무진` | WARN | 상투적 과장 | 사실이나 수치로 바꾸세요 |
| `(혁신적\|획기적\|압도적\|파격적)(인\|으로)` | WARN | 근거 없는 홍보 표현 | 측정 가능한 차이와 출처 |
| `원활(한\|하게)` | WARN | 측정할 수 없는 형용사 | 사용자가 하지 않아도 되는 일을 쓰세요 |
| `^(결론적으로\|요약하자면\|정리하자면\|종합하면)` | WARN | 방금 읽은 내용 반복 | 지우고 다음 행동으로 끝내세요 |
| `(효율적이고 효과적\|다양한 측면에서\|다각적인)` | WARN | 내용 없는 수식어 | 어떤 측면인지 쓰세요 |
| `(패러다임\|시너지\|인사이트를 (제공\|얻))` | INFO | 유행어 | 평이한 말로 |
| `(극대화\|최적화된\|지속 가능한\|핵심적인)` | INFO | 부풀린 수식어 | 정의된 의미가 있을 때만 |

## 높임과 UI 말투

| Pattern | Level | Why | Instead |
|---|---|---|---|
| `(나오셨\|품절이십\|되십니다\|있으십니다)` | WARN | 사물 존칭(국립국어원 2026 설문에서 93.3%가 개선 필요) | 나왔습니다, 품절입니다 |
| `하실 수 있으십니다` | WARN | 과도한 높임 | 하실 수 있습니다, 할 수 있어요 |
| `되어요` | WARN | UI 공간과 토스 가이드 기준 | 돼요 |
| `(실패했습니다\|수행에 실패)` | INFO | Microsoft: Failed to → "~하지 못했습니다" | 저장하지 못했습니다 |
